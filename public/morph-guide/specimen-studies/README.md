# Real specimen studies

These photographs are for the morph-learning review at the development-only `/DesignPreview#slider` route. The current live Morph Guide is unchanged.

`raindrop-right.webp` is the second photograph in the founder's already-public [Raindrop record](https://geckinspect.com/GeckoDetail?id=689e611c1b81f374051cd5b1). The founder's photographs are reused within the owner's requested morph-guide work. This is not a stock or public-domain image.

Original public storage asset: `base44.app/api/apps/68929cdad944c572926ab6cb/files/public/68929cdad944c572926ab6cb/e918a4df0_IMG_5981.jpeg` in the `geck-inspect-media` bucket. EXIF orientation was applied, the image resized to 1050 × 1400 and metadata stripped. The animal's color and markings were not retouched or generated.

The other study photos reuse the owner-authorized assets documented in `public/demo-geckos/README.md`. Unlike the fictional collection tour, this study uses the actual public animals' names and IDs. Raindrop's two views represent the same animal. “Facing left” and “facing right” describe the image orientation, not an asserted anatomical left/right side.

The photos were visually reviewed for the specific observations in `reviewStudyData.js` on October 14, 2026. Photo evidence is separated from keeper labels and from genetic inference. Raindrop's tail base is outside these frames, so the study does not assign a full/partial pinstripe grade from them.
